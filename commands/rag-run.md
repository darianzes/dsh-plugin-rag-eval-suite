请使用 `rag_eval_run`（或 `python3 -m rag_eval run`）：
1. 明确用户的执行粒度（单测试方法 / 单条用例 / 指定分类 / 核心集 / 全量批量 / 离线手动响应文件）；
2. 保持低资源并发（默认 `workers=2`），严格遵循可观测性边界（不编造不可观测的 Hit@K）；
3. 输出命中率、准确率、幻觉率、拒答率、延迟等核心指标及 95% 置信区间；
4. 按 P0/P1/P2/P3 分级汇报根因分析与对应的短期止血、结构修复及回归验证方案。
